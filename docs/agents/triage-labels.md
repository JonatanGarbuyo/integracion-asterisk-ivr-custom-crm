# Labels de trabajo

| Label | Uso |
|---|---|
| `needs-triage` | Solicitud pendiente de evaluación. |
| `needs-info` | Falta información para definir o ejecutar el trabajo. |
| `ready-for-agent` | Entrega definida; comprobar bloqueos y acceso antes de tomarla. |
| `ready-for-human` | Paso que debe ejecutar una persona. |
| `wontfix` | Trabajo descartado explícitamente. |
| `wayfinder:map` | Índice canónico de decisiones. |
| `wayfinder:research` | Investigación de hechos externos. |
| `wayfinder:prototype` | Prototipo para decidir con el usuario. |
| `wayfinder:grilling` | Decisión que requiere conversación con el usuario. |
| `wayfinder:task` | Paso previo que desbloquea una decisión. |
| `specification` | Especificación de alcance y conducta. |
| `implementation` | Entrega verificable de implementación. |
| `optional` | Mejora que requiere selección explícita; no bloquea la primera versión. |

La migración crea los labels usados por las issues. Los demás se crean cuando se necesitan.
